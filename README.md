# Генератор акцентов

Бесплатная утилита для барабанщиков на HTML и JavaScript. Каждое число — позиция акцента внутри доли. Такты отображаются крупным шрифтом: до четырёх в строке, в зависимости от ширины экрана и длины такта.

## Использование

Откройте https://creagent.github.io/drum-accent-generator/ и задайте число долей, нот в доле и тактов. Нажмите «Сгенерировать».

Для быстрого доступа добавьте страницу на главный экран телефона через меню браузера. На iPhone используйте Safari: «Поделиться» → «На экран Домой». На Android в Chrome: меню → «Добавить на главный экран» или «Установить приложение».

После появления надписи «Готово к работе без интернета» приложение можно открывать офлайн на этом устройстве, пока браузер сохраняет данные сайта.

## Публикация и обновления

GitHub Pages публикует корень ветки `main`. Сборка и сторонние зависимости не требуются. При изменении файлов, перечисленных в `APP_FILES`, увеличьте версию `CACHE_NAME` в `sw.js`.

Для локального использования можно открыть `index.html` в браузере. Установка и офлайн-кэш требуют HTTPS или локального HTTP-сервера на localhost.
